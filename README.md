# Learning resources - Python

This repository contains learning resources for Python. There is second part specialized in small project: [Arena Fighting Game](https://github.com/Dice-Sensei/arena-fighting-game).

## Acknowledgement

This repository was created as part of project between [Dice-Sensei](https://github.com/Dice-Sensei) and [SPŠ el-it Dobruška](https://spselitdobruska.cz/).
And can be used by any **human** for learning purposes.
Either as part of the school curriculum as an addition to it or for self-studying.

## Creation notes

Most of the code in this repository was created as part of the programming course.
It was live coded while explaining the purpose of the code and showing examples of usage.
This is not all the code produced but only what was left after the lecture.

These resources are being redacted and improved so they can be used as learning material even for people not attending the course.

## Purpose

The purpose of this repository is to store code written in lectures with explanations.
So students can review it later.
